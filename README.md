# Netflix-Dataset-Analysis-Python-Pandas
Este proyecto realiza un análisis exploratorio de datos (EDA) sobre el catálogo de Netflix utilizando Python, Pandas y Matplotlib. El dataset proviene de Flixable y contiene información sobre películas y series disponibles en la plataforma, incluyendo título, director, país, fecha de estreno, rating, duración y género.

---

## 📋 Contenido del proyecto

- Limpieza y preparación de datos.
- Funciones auxiliares para consultas específicas.
- Respuestas a preguntas clave con código, gráficos e interpretaciones:
  1. ID y director de *House of Cards*.
  2. Año con mayor número de estrenos.
  3. Comparación entre películas y series.
  4. Películas estrenadas en 2020.
  5. Programas de TV emitidos en India.
  6. Top 10 directores con más títulos.
  7. Análisis de audiencias (TV‑14 en Canadá, R post‑2018).
  8. Distribución de títulos por país (Top 10).
  9. Duración máxima de películas y series.

---

## 🚀 Tecnologías utilizadas

- **Python 3**
- **Pandas** para manipulación de datos
- **Matplotlib** para visualización
- **Jupyter Notebook** para documentación y ejecución

---

## 📈 Resultados

El análisis permite observar:
- Tendencias de estrenos por año (pico en 2019).
- Predominio de películas frente a series.
- Importancia de producciones locales (India, Canadá).
- Directores y países más representados.
- Distribución global del catálogo.
- Títulos más extensos en duración.
